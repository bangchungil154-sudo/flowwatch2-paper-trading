# 흐름감지 2.0 — 휴대폰 테스트용 배포 패키지

## 목표
온라인 서버에 배포한 뒤 휴대폰 브라우저로 접속해 업비트 공개 시세와 전략 A/B 모의매매를 테스트합니다. PC에서도 같은 주소로 접속할 수 있습니다.

## 무료 배포 준비 (Render + GitHub)
1. GitHub에 새 저장소를 만듭니다(예: `flowwatch2-paper-trading`).
2. 이 폴더 안의 파일 전체를 저장소 최상위에 업로드합니다. `server.js`, `package.json`, `render.yaml`, `index.html`, `app.js`, `style.css`가 최상위에 있어야 합니다.
3. Render 계정에서 **New + → Blueprint**를 선택하고 해당 GitHub 저장소를 연결합니다.
4. Render가 `render.yaml`을 읽으면 무료 Web Service 설정을 확인하고 배포합니다.
5. 배포가 끝나면 Render가 제공하는 `https://...onrender.com` 주소를 휴대폰에서 엽니다.

## 무료 플랜 관련 주의
- 무료 인스턴스는 사용하지 않을 때 잠들 수 있어 24시간 상시 운용을 보장하지 않습니다.
- 처음 접속할 때 서버가 깨어나느라 로딩이 오래 걸릴 수 있습니다.
- 서버 메모리에 기록을 보관하므로 재배포/재시작 시 모의매매 기록이 초기화될 수 있습니다.
- Render의 현재 무료 플랜 및 Blueprint 동작은 가입 시점의 공식 안내를 확인하세요.

## 로컬 실행
Node.js 18 이상에서 이 폴더를 열고 `npm start`를 실행한 뒤 `http://localhost:8787`로 접속합니다.

## 현재 기능
- 업비트 공개 KRW 마켓의 현재가 및 거래대금 상위 코인 표시
- 현재가 약 5초 주기 갱신, 상위 12개 마켓의 1분/5분 캔들 갱신
- 전략 A: 상승 초기 포착 / 전략 B: 상승 추세 눌림목 진입
- 전략별 초기자금 100만원으로 독립 모의매매
- 매수·매도 기록, 추정 수수료 매수/매도 각 0.05% 반영
- 실거래 주문 기능 없음

## 검증 전 주의
이 버전은 테스트용 초기 프로토타입입니다. 전략 수익성은 검증되지 않았으며, 신호 조건·슬리피지·체결 지연·API 제한을 충분히 검증하기 전에는 실거래에 사용하면 안 됩니다. 무료 호스팅은 장시간 연속 실행을 보장하지 않습니다.
